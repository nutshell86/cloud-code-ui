Leitplanken & Korrekturen · gilt für neue Chats

Randbedingungen, die in jedem neuen Chat gelten — ohne sie zu wiederholen. Sie werden als System-Hinweis übergeben und überleben damit auch eine Kompaktierung. Pro Chat lässt sich das im Tab-Menü ergänzen.

Die CLI zeichnet den System-Prompt beim ersten Request einer Sitzung auf und schickt beim Fortsetzen diese Aufzeichnung — auch wenn Leitplanken, Korrekturen oder Stil inzwischen geändert wurden, bis zur nächsten Kompaktierung. „aus" zeichnet nichts auf: laut CLI wird der Prompt bei jedem Request neu aufgebaut, Änderungen wirken also beim nächsten Fortsetzen — auch „Leitplanken jetzt anwenden". Preis, soweit gemessen: ein Fortsetzen mit geändertem Text und „aus" schrieb rund 16.500 Token in den Cache (mit „an": rund 500). Nicht gemessen: was „aus" bei unverändertem Text kostet und ob der Cache danach von Turn zu Turn wieder voll trifft. Gilt für Chats und Zeitpläne.

Lokale Browser-Oberfläche für die Claude Code CLI — Chat mit parallelen Sessions, Diff-Review, Token-Analytics, MCP, Skills und GUI-gesteuerte UI Skills. Pure Node, zero-dependency, bindet nur an 127.0.0.1.
